# Power BI Sales Dashboard

## Project Overview
An interactive sales dashboard developed using Microsoft Power BI where an Excel dataset was used to explore sales and profit performance.

## Objective
To develop practical data analytics and business intelligence skills by presenting sales data through an interactive visual dashboard.

## Tools Used
- Microsoft Power BI
- Power Query Editor
- Microsoft Excel

## Dashboard Features
- Total Sales and Total Profit KPI cards
- Sales by Category
- Sales by Sub-Category
- Sales by Region
- Sales Trend Over Time
- Interactive filters for Region, Category, and Order Date

## Skills Demonstrated
- Data import and preparation
- Data visualization
- KPI reporting
- Interactive dashboard development
- Business data analysis
